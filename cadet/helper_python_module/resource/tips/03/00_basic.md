# Module 03 개요

Module 03에서는 파이썬의 다양한 자료형과 기능을 활용하여 데이터를 처리하는 연습을 합니다.

이번 모듈에서 자주 사용되는 개념은 다음과 같습니다.

- Command Line Arguments (`sys.argv`)
- Tuple
- Dictionary
- Set
- Generator (`yield`)
- List Comprehension
- Dictionary Comprehension

---

## 자료형 선택 기준

|자료형|특징|
|---|---|
|list|순서가 있고 수정 가능|
|tuple|순서가 있고 수정 불가|
|dict|key-value 저장|
|set|중복 제거|
|generator|필요할 때 하나씩 생성|
